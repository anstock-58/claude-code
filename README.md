# claude-code

Dieses Repository verbindet **Claude Code** mit **GitHub** für den Benutzer `anstock-58`.

## Was ist eingerichtet

- GitHub MCP-Server Integration (Claude kann direkt mit GitHub interagieren)
- Automatische Git-Commit-Prüfung (Stop-Hook)
- Projekt-Einstellungen unter `.claude/settings.json`
- Projektdokumentation unter `CLAUDE.md`

## Verwendung

Claude Code kann in diesem Repository:
- Code lesen, schreiben und committen
- GitHub Issues und Pull Requests verwalten
- Branches erstellen und pushen
- Repository-Daten abrufen

## Backup

Alle gepushten Änderungen sind sicher auf GitHub gespeichert unter:
`https://github.com/anstock-58/claude-code`
